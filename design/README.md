# Astra Design-Bundle

- `DESIGN.md` – Richtlinien in Prosa, für Claude Code als Kontext gedacht.
- `tokens.css` – alle Farb-, Schrift- und Maß-Tokens als CSS-Variablen (dunkel Standard, hell über `data-theme="light"`).
- `tokens.json` – dieselben Tokens im W3C-Design-Tokens-Format (für Tailwind-Config, Style Dictionary o. ä.).
- `mockups/` – die Artboards als eigenständige HTML-Dateien (Tokens, Logo, Komponenten, fünf Seiten je Desktop + Handy). Im Browser öffnen; Markup und Inline-Styles als Vorlage verwenden.

Einbinden in ein Repo: Ordner als `design/` ablegen und in `CLAUDE.md` referenzieren, siehe Hinweis im Chat.
